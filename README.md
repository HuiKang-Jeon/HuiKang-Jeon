--------------------------------------------------
## 💡 About Me
이전 디자인 경험을 바탕으로 UI/UX 설계에 감각을 더하고,  
6개월 부트캠프를 통해 웹과 풀스택 개발의 기초부터 실무 프로젝트까지 경험하며  
프론트엔드 기능 구현, 백엔드 연동, 데이터베이스 관리, 모달과 상호작용 기능 구현 등  
전체 흐름을 책임지는 개발자로 성장하고자 합니다.

**HTML**, **CSS**, **JavaScript** 기본 문법과 **React.js** 및 **Flutter**를 활용한 **SPA**와 **앱 개발**,  
컴포넌트 기반 설계, 상태 관리, 반응형 웹 및 앱 UI 구현을 학습했고,  
**Java**와 **Spring Boot**를 활용한 **RESTful API** 설계, **MyBatis** 연동, **JSP**·**Thymeleaf** 템플릿 활용,  
**MySQL** 기반 데이터베이스 설계와 최적화, **Git/GitHub** 기반 협업과 코드 리뷰 등  
실무형 개발 환경을 경험했습니다.

프로젝트 진행 중 예상하지 못한 오류가 발생하더라도 원인을 분석하고  
관련 자료를 참고하여 다양한 방법을 시도하며 문제를 해결했으며,  
맡은 기능은 끝까지 구현하고 사용자 경험까지 고려하는 책임감을 갖추고자 노력했습니다.

**React** 기반 반려견 호텔 예약·관리 플랫폼과 **JSP/Servlet** 기반 영화 리뷰·토너먼트 사이트 프로젝트에서  
UI/UX 설계, 기능 구현, 데이터 연동, 모달/상호작용 기능을 전체적으로 경험하며,  
팀 프로젝트를 통해 문제 해결 능력과 협업 역량, 사용자 중심 설계 능력을 키웠습니다.

검증된 기술력과 사용자 경험 중심 사고를 바탕으로  
가장 효율적인 해결책을 제시하고 구현할 수 있는 개발자가 되겠습니다.
