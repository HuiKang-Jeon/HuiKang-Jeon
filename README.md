## 💡 About Me

이전 디자인 경험을 바탕으로 UI/UX를 고려한 개발을 지향하며,  
6개월 부트캠프를 통해 웹 풀스택 개발의 기초부터 실무 프로젝트까지 경험했습니다.  

프론트엔드 구현, 백엔드 연동, 데이터베이스 관리 등  
전체 개발 흐름을 이해하고 구현하는 역량을 갖추고 있습니다.

**HTML**, **CSS**, **JavaScript**, **React.js**, **Flutter**를 활용한 SPA 및 앱 개발과  
컴포넌트 기반 설계, 상태 관리, 반응형 UI 구현을 학습했으며,  
**Java**, **Spring Boot**, **MyBatis**, **JSP/Thymeleaf**, **MySQL** 기반의  
RESTful API 설계와 데이터베이스 활용 경험을 보유하고 있습니다.

프로젝트 과정에서 문제 발생 시 원인을 분석하고 다양한 방법으로 해결하며,  
맡은 기능을 끝까지 구현하고 사용자 경험까지 고려하는 개발을 지향합니다.

**React** 기반 반려견 호텔 플랫폼과 **JSP/Servlet** 기반 영화 리뷰 사이트를 통해  
UI/UX 설계부터 기능 구현, 데이터 연동까지 경험하며 협업 역량을 키웠습니다.

사용자 경험을 중심으로 효율적인 해결책을 구현하는 개발자가 되겠습니다.
